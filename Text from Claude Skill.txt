# Indian State Profile Skill

## Purpose
Produce a fast, accurate, source-linked fact-sheet for any Indian state to support scoping and business development. Output is tabular — each indicator row has: Value | National Rank | Reference Period | Source | Comments.

The profile is organised into six thematic blocks:
1. Basic Facts & Political Context
2. Economy & Labour
3. Public Finance
4. Human Development (Health · Nutrition · Education)
5. Physical & Digital Infrastructure
6. Institutional Infrastructure & Governance Capacity

Each block has a focused sub-structure. Sections that require web-searched live data (cabinet, key officials, SDG scores, policy event timestamps) are explicitly flagged.

---

## Step-by-Step Instructions

### Step 1 — Identify the state
Resolve common abbreviations: MP = Madhya Pradesh, UP = Uttar Pradesh, AP = Andhra Pradesh, TN = Tamil Nadu, HP = Himachal Pradesh, J&K = Jammu & Kashmir, etc.

### Step 2 — Read the source map
Read `references/source_map.md` before starting. It maps every field to its authoritative source and URL.

### Step 4 — Document fetch protocol (CRITICAL — read before searching)

Several sources in this profile contain many indicators in a single document — a state page, a PDF table, or a dashboard. **The correct approach is to fetch the document once and extract all relevant indicators from it in a single pass.** Searching field by field against these sources will produce false UNCONFIRMED results even when the data exists in the document.

**Apply this protocol for each multi-indicator source:**

**RBI Handbook of Statistics on Indian States**
- Fetch: rbidocs.rbi.org.in — search `RBI Handbook of Statistics on Indian States [latest year] site:rbi.org.in` to get the PDF URL, then fetch it
- In a single pass extract ALL of: GSDP (T21), per capita NDP (T20), unemployment rural/urban (T8/T9), agricultural wage (T113), CPI inflation (T108/T109), net sown area (T54), irrigated area (T55), foodgrain production (T62), forest cover (T99), groundwater (T107), birth rate (T2), death rate (T3), life expectancy (T7), IMR SRS series (T4), MMR (T5), TFR (T6)
- Do NOT run separate searches for each RBI indicator — one fetch, all fields

**NITI Aayog SDG India Index**
- Fetch the state-specific dashboard URL directly (no PDF, no search needed):
  sdgindiaindex.niti.gov.in/#/state-compare?goal=AllGoal&area=[STATE_CODE]&timePeriod=2021
  Known state codes: IND036=Telangana; IND035=Andhra Pradesh; IND029=Karnataka; IND033=Tamil Nadu; IND021=Odisha; IND027=Maharashtra; IND009=Gujarat; IND005=Rajasthan; IND024=Madhya Pradesh; IND031=Uttar Pradesh; IND010=Bihar
  If the code is unknown, fetch sdgindiaindex.niti.gov.in/#/ranking to identify it
- Extract in one pass: composite score + all 16 goal-wise scores
- Do NOT attempt to parse any PDF (not machine-readable). Do NOT run separate searches per goal.

**NFHS-5 state factsheet**
- Fetch: try rchiips.org/nfhs/NFHS-5Reports/[State].pdf first; if blocked try dhsprogram.com/pubs/pdf/OF43/OF43.[code].pdf; if blocked try the NITI Aayog SNP report for the state
- In a single pass extract ALL NFHS-5 indicators in the profile: TFR, sex ratio at birth, institutional delivery, 4+ ANC visits, full immunisation, stunting, wasting, underweight, child anaemia, women anaemia, pregnant women anaemia, households with electricity, improved drinking water, clean cooking fuel, women with mobile phone, women with bank account, birth registration
- Do NOT run separate NFHS searches per indicator — one fetch, all fields

**SRS Statistical Report**
- Fetch: search `SRS Statistical Report [latest year] PDF site:censusindia.gov.in` then fetch
- In a single pass extract: IMR, U5MR, birth rate, death rate, life expectancy, TFR (cross-check)
- SRS Special Bulletin on MMR: separate fetch for MMR only

**Health Dynamics of India (Infrastructure & HR)**
- Fetch: mohfw.gov.in/sites/default/files/Health Dynamics of India (Infrastructure & Human Resources) 2022-23 — search `"Health Dynamics of India" 2022-23 site:mohfw.gov.in` then fetch the PDF
- In a single pass extract: Sub-Centres, PHCs, CHCs, Sub-District Hospitals, District Hospitals, beds, private hospitals for the specific state

**PRS Budget Analysis**
- Fetch: prsindia.org/files/budget/budget_state/[state]/[year]/Budget_Analysis_[year]-[state].pdf
- In a single pass extract: total expenditure, revenue expenditure, capital outlay, loans given, own tax revenue, fiscal deficit % GSDP, outstanding liabilities, committed expenditure %, FC devolution, top 3 sector allocations

**Census of India**
- Fetch: censusindia.gov.in — state-level tables for the specific state
- In a single pass extract: population, density, urban %, sex ratio, SC %, ST %, literacy (aged 7+), kuccha houses %

**If a fetch fails or returns no usable content:** flag the entire source as `[UNCONFIRMED — [source name] fetch failed]` for all indicators from that source. Do not then run individual field searches against the same source — that will not succeed if the fetch failed.

**What news articles and state govt press releases ARE permitted for (and only for):**
- Institutional existence: remote sensing agency, e-governance society, CM fellowship, challenge fund, training institute, grievance portal, vision document, advisory council, caste census
- Current names: cabinet ministers, secretaries, CM
- Policy event timestamps: stamp duty revision year, pay commission date, election dates, industrial policy year

- Political context: ruling party, CM, date of assumption, recent announcements not yet on official portals

### Step 4 — Apply the hallucination guard (NON-NEGOTIABLE)
- Confirmed from search → fill with value + source URL
- Not confirmable from search → `⚠️ Not confirmed — verify at [source URL]`
- NEVER estimate, interpolate, or recall from training data without flagging
- Paywalled or inaccessible → `Not available — [reason]`

### Step 5 — Populate the template
Fill every row. Every column must be filled. Use `—` only when genuinely not applicable.

### Step 6 — Output
**NO INTERMEDIATE STEPS. NO NARRATION. NO SEARCH SUMMARIES.**
Do all research silently. Do not display search queries, fetch attempts, intermediate findings, or commentary about what you are doing or what failed. The user sees only two things:

1. The completed CSV file (presented via the file tool)
2. A brief summary paragraph (100 words max) noting: which primary sources were successfully fetched, which were blocked/inaccessible (and why), and how many rows remain [UNCONFIRMED] as a result

Nothing else. No "Let me now fetch..." or "I found that..." or "Moving on to...". Run all fetches and searches silently, then output the file and the summary.

## Column Definitions

| Column | Content |
|---|---|
| **Value** | Number (with unit), Yes/No, or 2–3 sentence answer |
| **Rank** | National rank among 28 states + 8 UTs where meaningful. `—` if not rankable. `⚠️` if unconfirmed. |
| **Ref. Period** | Year or survey round (e.g. "2023-24", "NFHS-5 (2019-21)", "Census 2011") |
| **Source** | Short name + URL |
| **Comments** | Rank direction, data caveats, staleness warnings, or `—` |

**Rank direction must always be stated in the Comments column** (e.g. "Rank 1 = largest", "Rank 1 = worst/highest").

## EXPLANATORY NOTES FOR INSTITUTIONAL FLAGS

**NOTE A — Dedicated Data Analytics Unit (DAU)**
A small specialised unit of data scientists embedded in a core government department (typically Planning, Finance, or Directorate of Economics & Statistics) with an explicit mandate to analyse administrative data and produce decision-support outputs for senior officials. This is distinct from a general IT department or NIC data centre. Benchmark examples: Tamil Nadu's DAU within the Directorate of Economics and Statistics — announced in Budget Speech 2015-16, the first such unit in India, operated in collaboration with TNeGA (des.tn.gov.in/en/node/40); Andhra Pradesh's DAU under Finance Dept / APCFSS, which co-develops analytical frameworks with line departments (dau.apcfss.in). Search: "[State] data analytics unit planning statistics finance" OR "[State] DAU evidence-based policy". If found: full name, parent department, year established, website.

**NOTE B — Integrated State Resident Dataset / Unified Beneficiary Registry**
A cross-departmental, deduplicated citizen database linking records across welfare schemes and service delivery systems using a common state-level unique identifier. A strong indicator of data infrastructure maturity — enables DBT rationalisation, duplicate elimination, and cross-programme targeting. Benchmark examples: Samagra Vedika (Telangana) links welfare data across departments using a state household ID; Makkal ID / TN e-Governance (Tamil Nadu). Search: "[State] integrated beneficiary database" OR "[State] unified resident registry" OR "[State] Samagra equivalent" OR "[State] household registry welfare data". If found: full name, year launched, coverage (residents / schemes linked), website.

**NOTE C — State Transformation / Policy Advisory Institution**
A dedicated institution under the Planning Department or CMO providing in-house policy research, programme management support, and capacity building to the state government — functioning as a state-level NITI Aayog equivalent. Some are affiliated with NITI Aayog's State Support Mission (niti.gov.in/divisions/mission/state-support-mission). Search: "[State] institute of transformation" OR "[State] state support mission" OR "[State] good governance institute" OR "[State] institute for development policy". If found: full name, parent department, year established, website.

**NOTE D — State Technology / e-Governance Society**
A registered society or autonomous body mandated to design, procure, and manage the state government's technology and data systems for service delivery. The primary technology implementation arm of the state, typically controlling significant IT budget and data infrastructure. Benchmark examples: Centre for Good Governance (CGG) — Telangana/AP (cgg.gov.in); Centre for e-Governance (CeG) — Karnataka (ceg.karnataka.gov.in); Tamil Nadu e-Governance Agency (TNeGA) — Tamil Nadu (tnega.tn.gov.in). Search: "[State] e-governance society" OR "[State] centre for good governance technology" OR "[State] IT agency government society". If found: full name, year established, parent department, website.

**NOTE E — CM Economic / Advisory Council**
Some Chief Ministers have constituted a formal advisory council of external experts (economists, academics, former officials) to provide independent guidance on economic and social policy. This signals the government's openness to technocratic input and evidence-based policymaking. Well-documented examples: Tamil Nadu CM's Economic Advisory Council (Duflo, Rajan, Drèze, Arvind Subramanian, S Narayan — constituted 2021); Odisha CM's Economic Advisory Council (announced 2025). Search: "[State] chief minister economic advisory council" OR "[State] CM advisory council economists" OR "[State] economic advisory council members". If found: note full name, members, year constituted, and whether currently active.

**NOTE F — Caste Census**
A caste census (also called OBC survey or socio-economic caste survey) is a state-conducted enumeration of caste-wise population beyond SC/ST. As of 2025, only a few states have conducted these: Bihar released its Caste Survey data in October 2023; Telangana conducted a Comprehensive Household Survey (Gruha Lakshmi / Samajik, Aarthik, Jaati Ganana) with caste enumeration in 2023-24; Karnataka conducted a caste survey. Most states have not. Search: "[State] caste census survey year" OR "[State] OBC survey population data" OR "[State] socio-economic caste enumeration". If Yes: note the year conducted, who conducted it, whether data was publicly released, and key finding if available. If No: state "No state-level caste census conducted as of [year]."

**NOTE G — Regional Development / Planning Boards**
Some large states have constituted statutory or executive boards to address regional imbalances within the state — providing dedicated development funds, planning authority, and administrative focus to historically underdeveloped sub-regions. These are distinct from the state planning commission and operate at the sub-state level. Well-documented examples: Kalyana Karnataka Regional Development Board (KKRDB) — for the six districts of the Hyderabad-Karnataka region (kkrdb.karnataka.gov.in); Vidarbha Development Board and Marathwada Development Board in Maharashtra; Bundelkhand Development Board in UP/MP. Search: "[State] regional development board" OR "[State] regional planning board" OR "[State] backward region development board" OR "[State] area development authority". If found: list each board's full name, the sub-region it covers (list districts if possible), year established, legal basis (Act / GO), and website.

**NOTE H — Out-of-budget / Challenge Fund**
Some states operate a discretionary fund — outside the normal departmental budget cycle — that departments, districts, or implementing agencies can apply to on a competitive basis, in order to access supplementary financing for innovation, pilots, or scale-up. These are sometimes called challenge funds, innovation funds, or competitive grant schemes. They are distinct from normal budget allocations and from centrally-sponsored scheme funds. They are also distinct from the National Urban Innovation Challenge Fund (do not count this). Well-documented examples: TANII (Tamil Nadu Innovation and Incubation fund — tanii.tn.gov.in); Telangana's SERP Challenge Fund (Rs 12.66 crore for SHG women-led enterprises, 2026). Search: "[State] challenge fund government departments" OR "[State] innovation fund districts apply" OR "[State] competitive grant departments" OR "[State] out of budget fund". If found: name of fund, administering body, size (Rs crore), who can apply, purpose, and URL.

## Hallucination Guard — Strict Rules (NON-NEGOTIABLE)

1. **No memory fills.** Every number, name, and Yes/No must come from a web search in this session.
2. **Unconfirmed = flagged.** Cannot confirm from search → `⚠️ Not confirmed — verify at [source URL]`.
3. **Fixed source assignments are non-negotiable.** The table in Step 3 assigns one source per indicator category. That source is the only permitted source. If it is inaccessible: flag `[UNCONFIRMED - verify at source URL]` and state the access barrier. Never silently substitute a news article, a Wikipedia entry, or a secondary aggregator — even if the figure they cite appears identical to what the primary source would show. The citation must point to the primary source, not to something that quoted it.
4. **Names especially.** Cabinet and secretary postings change frequently. Always search live. Never fill from memory.
5. **Ranks from search.** Never compute from memory. Derive from a source table or search `[indicator] state-wise India ranking`. Unconfirmed → `⚠️`.
6. **Institutional flags.** Do not assume existence. Search each explicitly. News articles and state govt portals are acceptable for institutional Yes/No questions.
7. **Stale data.** If best available is >3 years old, flag in Comments. Never substitute a guess.
